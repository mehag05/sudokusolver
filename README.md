A Sudoku solver using AC3 search, inference (which uses board logic as well as AC3), and guessing (which uses inference and randomly guessed values)!
(Note guessing is the most accurate method.)
Run python3 sudoku_gui.py to see the agent in action!
(Note the input format for a board is an 81 integer long input with 0s as empty cells)
Example: 004300209005009001070060043006002087190007400050083000600000105003508690042910300
